The architectural guarantee

Tools are the source of truth; the LLM only reasons over what they return. Every number an agent states came from a deterministic read against the live store, so the platform stays auditable — a requirement for anything touching battery safety or regulatory reporting. The orchestrator degrades to deterministic planning and template synthesis when no model key is present, so a demo never depends on an external API.

Battery Pack Aadhaar is a draft MoRTH scheme — implemented for compliance-readiness, not as a live regulatory integration. NASA PCoE data retrieved via community mirror (CC0).

# VoltEdge AI

**AI for Industrial EV Supply Chain & Asset Intelligence**
ET AI Hackathon 2026 — Problem Statement 3

An intelligence layer over four asset domains — battery health, fleet electrification,
multi-tier supply chain, and manufacturing quality — joined by one rule: every figure
the system reports traces back to the tool call that produced it.

---

## Running it

Two servers, two terminals.

**Backend** — FastAPI on port 8000:

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

**Frontend** — Next.js on port 3000:

```bash
cd frontend
npm install
npm run dev
```

Then open <http://localhost:3000>.

> **You must run `uvicorn` from inside `backend/`.** It resolves `main:app` relative to the
> working directory, so running it from the repo root fails with
> `Error loading ASGI app. Could not import module "main"` — which looks like a code error
> but is a path error.

### Enabling the LLM agents

Without a key the orchestrator runs in **deterministic** mode: it still plans, calls tools and
answers correctly, using template synthesis. With a key it uses Gemini for planning and
synthesis. Set it in the same terminal, before starting the backend:

```bash
export GEMINI_API_KEY="your-key-here"
```

On Windows PowerShell:

```powershell
$env:GEMINI_API_KEY = "your-key-here"
```

Startup then logs `[OK] Agent orchestrator online` instead of `[WARN] No LLM key`, and the
Agent Console badge reads `LLM` rather than `DETERMINISTIC`.

### Also worth opening

- <http://localhost:8000/docs> — FastAPI's interactive explorer. All 41 endpoints are
  browsable and executable.

## On data provenance

This matters more than any single number, and the app labels it everywhere.

**Battery degradation is validated on real data.** `backend/data/nasa/` holds four
room-temperature cells from the NASA Prognostics Center of Excellence Li-ion ageing dataset
(CC0), retrieved via a community mirror because NASA's own portal no longer serves the files.
See [`backend/data/nasa/SOURCE.md`](backend/data/nasa/SOURCE.md) for provenance and for the
seven cells that were deliberately **excluded** — one terminates at 0.000 Ah and four show
capacity *increasing* across the test.

For reference, the same model scores far better on our synthetic fleet (0.475 %SoH RMSE) than
on real cells (2.281). That gap is the point: fitting data generated by a process you wrote
yourself is partly circular. The real-cell figure is the honest one, and it is what the UI
leads with.

**Manufacturing quality data is synthetic.** Gigafactories do not publish defect data and
there is no open cell-manufacturing defect corpus to vendor. Precision and recall are measured
on generated batches with a known causal structure, and the Quality page says so on screen.
What transfers to real line data is the pipeline: the feature construction, the SPC baseline,
the held-out evaluation, and the safety-weighted operating point.

**Carbon figures are modelled**, with the assumptions exposed through the API rather than
buried — `grid_factor_kg_per_kwh` (CEA 0.71) and `renewable_depot_share_pct` (30%) are
returned in `/api/carbon/summary` so a reviewer can check them.

**Battery Pack Aadhaar is a draft MoRTH scheme.** The BPAN module is built for
compliance-readiness. It is not a live regulatory integration, and should not be presented as
one.

## Notable findings

Two results are worth stating plainly, because they look like weaknesses and are not:

**21 of 30 diesel vehicles have no viable EV replacement.** Payload and range matching rejects
gross over-specification — a 1,200 kg pickup is not replaced by a 4,200 kg truck. Medium and
heavy e-trucks also fail their 7-year TCO case at current capital cost. This is precisely why
industrial EV penetration sits below 2.5%, and a tool that hides it by recommending a
three-wheeler for a ten-tonne truck is not being helpful.

**Adding in-line inspection barely improves defect detection** (AUC +0.001 over process data
alone). The inspection signals are consequences of the same process excursions, so they carry
little independent information — which means the process data is sufficient, and it arrives
first.

## Stack

- **Backend** — FastAPI, scikit-learn, NumPy, pandas. In-memory seeded store, no database.
- **Frontend** — Next.js 16, React 19, Recharts, CSS Modules.
- **Agents** — custom orchestrator (planner → specialists → synthesiser) over a 10-tool
  registry, Gemini optional.

Data regenerates in memory on every backend restart from a fixed seed, so vehicle IDs stay
stable across restarts — but they will shift if the model code changes. Re-check any figures
you put in slides after a code change.
